# kht-mppt-monitor

מוניטור לבקר הטעינה **KHT 200W MPPT**. ESP32-WROOM-32 קורא את פורט התקשורת של הבקר ומגיש דף לטלפון.

הטלפון מתחבר לרשת של הבקר עצמו. אין צורך בראוטר.

| | |
|---|---|
| רשת | `KHT-MPPT` |
| סיסמה | `mppt1234` |
| דף | http://192.168.4.1 |

הסיסמה והפינים נמצאים ב־`include/config.h`.

## חיבור

על תקע התקשורת של הבקר: **G** אדמה, **T** שידור מהבקר, **R** קליטה בבקר, **V** מתח.

| בקר | ESP32 |
|---|---|
| G | GND |
| T | GPIO16 ‏(RX) |
| R | לא מחובר |
| V | לא מחובר |

הבקר שולח לבד כל 100 ms. אין צורך ב־R.

לפני חיבור של T: למדוד את המתח בין T ל־G כשהבקר דולק. אם המתח סביב 3.3 V, חיבור ישיר מתאים. אם הוא סביב 5 V, שים מחלק: 1 kΩ מ־T אל GPIO16, ו־2 kΩ מ־GPIO16 אל GND. כניסת ה־ESP32 אינה סובלת 5 V.

את פין V לא מחברים ל־ESP32.

מתג ה־DIP על הלוח בוחר מתח סוללה בחומרה. הוא לא נקרא דרך הפורט.

## צריבה

חבר את לוח ה־ESP32 ב־USB, ואז לחץ פעמיים על `scripts\flash.bat`.

אם יש כמה יציאות טוריות:

```bat
scripts\flash.bat COM5
```

ההרצה הראשונה מתקינה את PlatformIO ומורידה את ערכת הכלים של ESP32. זה לוקח כמה דקות. סגור מוניטור טורי שתופס את היציאה לפני הצריבה.

## מה מוצג

מתח טעינה, זרם, הספק, טמפרטורה פנימית, טמפרטורה חיצונית, ומצב:

- `1` בטעינה
- `2` הטעינה הסתיימה
- `4` יש כניסה, אבל אין אספקת טעינה

אם בתים מגיעים והמסגרות התקינות נשארות 0, קצב השידור כנראה שונה. ברירת המחדל היא 9600 8N1, ב־`MPPT_BAUD`.

## המסגרת

12 בתים. לפי המקרא הממוספר, הדוגמה היא:

`5A 81 93 00 00 00 01 00 00 1C 55 FB`

שורת הדוגמה בראש הדף של היצרן מכילה `00` מיותר. המספור וה־BCC מסכימים על 12 הבתים שלמעלה.

| בתים | שדה | יחידה |
|---|---|---|
| 0 | התחלה `5A` | |
| 1 | מצב. `0x80` והספרה הנמוכה: 1 / 2 / 4 | |
| 2–3 | מתח טעינה, בית נמוך קודם | 0.1 V |
| 4–5 | זרם טעינה | 0.1 A |
| 6–7 | הספק טעינה | 0.1 W |
| 8 | NTC חיצוני. `00` = אין קריאה | °C |
| 9 | NTC פנימי | °C |
| 10 | BCC: `0x5A` XOR בתים 1 עד 9 | |
| 11 | סוף `FB` | |

בדוגמה: 14.7 V, זרם 0, הספק 0.1 W, 28 °C בפנים, מצב בטעינה.
